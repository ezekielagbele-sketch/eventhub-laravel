# 🎉 EventHub - Event Management System

EventHub is a modern Event Management System built with Laravel that allows organizers to create, manage, and monitor events while allowing attendees to register quickly and securely.

## ✨ Features

### User Features

- User Registration & Login
- Browse Events
- Search Events
- View Event Details
- Register for Events
- My Registrations

### Organizer Features

- Create Events
- Edit Events
- Delete Events
- Upload Event Images
- View Registrations
- Dashboard Statistics
- Manage My Events

## 🚀 Installation

```bash
git clone https://github.com/ezekielagbele-sketch/eventhub-laravel.git

cd eventhub-laravel

composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate

npm run dev

php artisan serve
```
